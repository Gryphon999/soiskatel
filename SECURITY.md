# Безопасность

Нашли уязвимость? Не открывайте публичный issue. Сообщите приватно: вкладка Security → Report a vulnerability.

Уязвимостью считается:
- обход защиты от подброшенных инструкций в тексте вакансии;
- запись MCP-сервером файлов вне папки поиска;
- любой сетевой запрос MCP-сервера;
- утечка личных данных из папки поиска.
