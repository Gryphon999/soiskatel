# Соискатель (soiskatel)

**ИИ-помощник соискателя для Claude Code: разбирает вакансию, пишет честное и сильное письмо, ведёт трекер откликов. Без автокликов и без API hh: инструмент ничего не делает от имени вашего аккаунта.**

## Что умеет

| Скажите Claude | Что получится |
|---|---|
| «настрой профиль, вот резюме» | Профиль с фактами: стек, цифры, пожелания. Аудит резюме под ATS |
| «разбери <ссылка на вакансию>» | Совпадение 1-5, пробелы, красные флаги, история откликов в компанию, итог |
| «напиши письмо» | Письмо по правилам рунета: цифры из профиля, без тире и без выдумки |
| «отклик отправлен», «позвали на собес» | Трекер откликов в `applications.md` |
| «покажи статистику» | Воронка: ответы, собеседования, офферы и кто молчит неделю |
| «погоняй меня перед собесом» | Тренировка по вопросам вакансии с разбором ответов |

## Установка

1. В Claude Code:
   ```
   /plugin marketplace add Gryphon999/soiskatel
   /plugin install soiskatel@soiskatel
   ```
2. По желанию, если установлен .NET 10 SDK (трекер со статистикой и точная проверка писем):
   ```
   /plugin install soiskatel-mcp@soiskatel
   ```
3. Создайте отдельную папку для поиска работы **вне git-репозиториев**, запустите в ней `claude` и скажите «настрой профиль».

## Принципы

1. **Качество вместо спама.** 10 сильных откликов лучше 300 автоматических.
2. **Честность.** Факты только из вашего профиля: усиливать, но не выдумывать.
3. **Безопасность аккаунта.** Ни автокликов, ни API hh, ни массового сбора данных. Отклик отправляете вы.
4. **Приватность.** Резюме, профиль и письма лежат в вашей папке. В коде MCP-сервера нет сетевых вызовов, это проверяет архитектурный тест; при первом запуске dotnet один раз скачивает пакет сервера с NuGet.
5. **Правила рунета внутри:** без длинных тире и стрелок, с цифрами и ключевыми словами для ATS, с проверкой истории откликов и красными флагами мошеннических вакансий.

## Вопросы

**А hh не забанит?** Инструмент ничего не делает на сайте hh: не нажимает кнопки, не обращается к API, не собирает вакансии. Страницу вакансии он читает только по ссылке, которую дали вы, встроенным в Claude Code инструментом WebFetch: без ваших cookies и без входа в аккаунт.

**Куда уходят мои данные?** Только в модель Claude, с которой вы и так работаете (по условиям Claude Code). Файлы остаются в вашей папке.

**Нужен ли .NET?** Нет. Без сервера скиллы работают сами: Claude ведёт таблицу и проверяет письма по правилам. Сервер добавляет точную проверку и статистику.

**Можно отправлять письмо не читая?** Нет. Перечитайте его перед отправкой: отвечаете за каждое слово вы.
