# Аудит резюме под ATS и рынок рунета

Проверяй по пунктам. Советы короткие и конкретные: «было» и «стало».

1. **Заголовок** совпадает с ролью, на которую человек откликается: «C# / .NET разработчик», а не «Программист».
2. **Технологии полностью и аббревиатурой**: «Entity Framework Core (EF Core)», «ASP.NET Core», «PostgreSQL». Системы отбора резюме (ATS) ищут по ключевым словам, так совпадений больше.
3. **Цифры**: у каждого места работы и проекта хотя бы один результат с числом.
4. **Активные глаголы**: спроектировал(а), реализовал(а), ускорил(а), автоматизировал(а). Без «участвовал в разработке».
5. **Без слабых сторон и оправданий** в тексте резюме.
6. **Длина**: одна-две страницы; старый опыт не по профессии одной строкой.
7. **Вёрстка, которую не читают ATS**: таблицы и колонки в PDF, текст на картинках, необычные названия разделов. Лучше простой документ.
8. **Ссылки**: GitHub и портфолио кликабельны и открываются без входа.
9. **Длинные тире и стрелки**: заменить запятыми, двоеточиями и обычными дефисами.
10. **Навыки, к вопросам по которым человек не готов**: предложить убрать или понизить уровень.
