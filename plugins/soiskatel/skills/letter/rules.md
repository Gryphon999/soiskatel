# Правила сопроводительного письма

## Структура: 4-6 коротких абзацев
1. **Зацепка:** одна фраза о том, что в этой вакансии совпадает с опытом: их стек, домен или задача.
2. **Цифры:** 1-2 результата из профиля, самые близкие к вакансии.
3. **Проекты:** 1-2 подходящих проекта, суть в одну фразу, ссылка, если она есть в профиле.
4. **Стек:** технологии вакансии, которые есть в профиле, полным названием и аббревиатурой: Entity Framework Core (EF Core).
5. **Формат работы:** удалёнка, офис или гибрид, город. Только то, что есть в профиле.
6. **Подпись и контакты** из профиля.

## Стиль
- Без длинного и короткого тире и без двух дефисов подряд. Вместо них запятая, двоеточие или новое предложение. В диапазонах чисел обычный дефис: 9-18.
- Без стрелок.
- Активные глаголы: спроектировал(а), реализовал(а), ускорил(а), автоматизировал(а). Без слова «участие».
- Без канцелярита и штампов: «являюсь», «в рамках», «данный», «важно отметить», «в современном мире».
- Без слабых сторон и оправданий: не пиши, чего нет, сколько лет не хватает, что опыт «некоммерческий».
- Без выдумки: только факты из профиля.
- Коротко: обычно 600-1200 символов. Для staff.am не больше 500 символов.

## Проверка (если нет MCP-сервера)
- [ ] нет длинного и короткого тире, двух дефисов подряд и стрелок;
- [ ] нет слова «участие» и его форм;
- [ ] есть хотя бы одна цифра;
- [ ] все факты есть в profile.md;
- [ ] нет слабых сторон и оправданий;
- [ ] длина в пределах лимита площадки.
