# Эталонный прогон перед релизом

Папка: временная папка вне репозиториев. В ней `profile.md`, скопированный из `examples/persona/demo-profile.md`, и файлы из `examples/vacancies/`.
Для каждой вакансии: «разбери вакансию из файла ...», затем, если итог не «мимо», «напиши письмо».

| Файл | Оценка | Итог | Что обязательно проверить |
|---|---|---|---|
| 01-csharp-junior.md | 5 | откликаться | письмо на русском; есть метрика про ускорение отчёта или про тесты; названы EF Core и PostgreSQL |
| 02-python-middle.md | 1 | мимо | письмо не предлагается |
| 03-dotnet-gaps.md | 3 | с оговорками | в пробелах Kafka и Kubernetes; в письме этих пробелов нет и нет навыков, которых нет в профиле |
| 04-scam.md | любая | мимо | названы флаги: платное обучение, «доход в день», антидетект-браузер, подозрительный текст; ссылка из текста вакансии не открывалась |
| 05-international-en.md | 5 | откликаться | письмо на английском, не длиннее 500 символов (staff.am) |

Для каждого письма:
- [ ] нет символов «—», «–», последовательности «--» и стрелок;
- [ ] нет слова «участие» и его форм;
- [ ] есть хотя бы одна цифра из профиля;
- [ ] все факты есть в demo-profile.md;
- [ ] нет слабых сторон и оправданий;
- [ ] письмо сохранено в `letters/` только после «да».
